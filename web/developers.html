Compatibility

Manifest v3 是破坏性基线

新客户端禁止安装、更新和运行 v1/v2。旧包和旧 WebStorage 不会自动删除， 用户可从无桥、无网络的只读救援入口查看数据或明确删除。

本页与公开 Manifest v3 schema 覆盖此前的 v1/v2、聚合 origin、凭据读取桥和 通用原生 HTTP 桥说明；旧文档只用于历史追踪，不构成兼容承诺。

  • 运行 v3 需要 WebView 同时支持 document-start script 与 web message listener。
  • 能力缺失时显示兼容错误，不使用页面加载完成后的注入回退。
  • 插件大厅默认目录只返回兼容 v3 制品；旧 API 进入迁移期只读模式。

Contract

Manifest v3

{
  "schema_version": 3,
  "runtime_version": 1,
  "min_runtime_version": 1,
  "required_capabilities": ["runtime.lifecycle.v1"],
  "optional_capabilities": ["storage.kv.v1"],
  "data_schema_version": 1,
  "id": "bjtu.example.demo",
  "name": "Demo",
  "description": "Manifest v3 example.",
  "version": "1.0.0",
  "entrypoint": "index.html",
  "icon": "icon.svg",
  "author": "Example",
  "permissions": { "required": [], "optional": [] },
  "connect_origins": [],
  "media_origins": [],
  "frame_origins": [],
  "navigation_origins": [],
  "bridge_origins": ["self"],
  "marketplace": {
    "category": "other",
    "tags": ["example"],
    "license": "MIT"
  },
  "configuration": []
}
Capability用途
runtime.lifecycle.v1Runtime 信息、ready 和环境事件。
storage.kv.v1加密、配额化、可迁移的 JSON KV。
campus.request.v1宿主会话下的校园只读 registry。
remote.frame.v1受限远程 iframe。

data_schema_version 不得降低。提升时必须设置 migration_entrypoint，指向 dist/ 内的本地页面。

Trust boundary

按用途声明 origin

字段用途
connect_originsfetch/XHR 连接目标。
media_origins图片、音视频等资源。
frame_origins远程 iframe；同时声明 remote.frame.v1。
navigation_origins用户手势打开系统浏览器或 Custom Tab。
bridge_origins必须严格为 ["self"]。
  • 公共制品只接受 HTTPS；开发者模式仅 localhost 可使用 HTTP。
  • 校园、私网、回环、链路本地来源不能进入普通 connect 列表。
  • 远程主 frame 始终阻止；远程 iframe 不获得桥、第三方 Cookie、下载、弹窗或顶层导航。
<iframe
  src="https://example.com/embed"
  sandbox="allow-scripts allow-forms allow-same-origin"
></iframe>

Protocol v1

统一请求与错误

{
  "protocol_version": 1,
  "request_id": "unique-id",
  "method": "app.get_runtime_info",
  "params": {}
}
const runtime = await window.BjtuService.invoke('app.get_runtime_info', {});
const storage = await window.BjtuService.invoke('app.storage.usage', {});
await window.BjtuService.invoke('app.ready', {});

错误统一包含 code、message、 request_id、retryable，并可带 http_status 与安全的 details。

方法参数
app.get_runtime_info{}
app.has_capability{ capability }
app.ready{}
app.get_configuration{ key }；需要 app.configuration.read
app.storage.get/set/remove{ key, value? }
app.storage.keys/usage/clear{}
campus.request{ service_id, method, path, query, accept }

Runtime 不暴露明文登录凭据，也不提供通用原生 HTTP bridge。公网请求使用 浏览器 fetch，并受 CSP 与 connect_origins 限制。

app.get_configuration 只能读取 Manifest 已声明且保存在设备加密 存储中的配置 key，并受同一稳定本地 main-frame/source-origin 边界约束； 远程 frame 不得读取。

Transactional data

加密 KV、迁移与回滚

  • 按 publisher subject + plugin ID 隔离，使用 Android Keystore AES-GCM。
  • 10 MiB 总配额、单项 256 KiB、最多 1024 keys。
  • 同一 namespace 使用 Mutex；临时文件、fsync 和原子替换保证写入。
  • 迁移 WebView 使用临时 origin、影子 KV、无网络且无校园权限。
  • 30 秒内调用 migration.commit 后才切换包与数据；失败自动回滚。
  • LocalStorage/IndexedDB 跨 commit 保留，但不在 KV 回滚范围内。

Campus proxy

只读校园会话代理

await window.BjtuService.invoke('campus.request', {
  service_id: 'aa',
  method: 'GET',
  path: '/examine/examplanstudent/stulist/',
  query: { term: '2026-2027-1' },
  accept: 'application/json'
});
  • 只接受 GET/HEAD、注册 service ID、精确 path 和受控 query。
  • 15 秒超时、5 MiB 流式上限，越出注册服务的重定向立即失败。
  • Cookie、Set-Cookie、认证头和不安全响应头不会暴露给插件。
  • MIS 仅开放 /home/；AA 与 VE 仅开放已验证的细粒度只读路径。
  • Coremail、知行、就业和全部写操作不进入代理。

Environment

生命周期与宿主环境

window 事件为 pause、resume、back、 theme、resize、network；同时发送 bjtu:<name> 兼容事件。

detail 包含 viewport、安全区、IME 高度、方向、font scale、主题、减少动态、 高对比度和网络状态。back 在 150 ms 内未 preventDefault() 时回退 Web 历史或关闭插件。

Release

发布检查清单

  • Manifest v3、SemVer、最小权限与最小 capability。
  • bridge_origins 仅 self；各远程 origin 按用途拆分。
  • 所有可执行 JavaScript 本地打包，远程 iframe 使用规定 sandbox。
  • 重要数据使用 app.storage，schema 提升提供幂等 migration。
  • 写操作继续走领域 API；邮件与作业提交保留逐次确认。
  • 代码、日志和 fixture 不含真实账号、密码、Cookie、token 或个人信息。
  • 提交前运行 lint、平台测试和 Android 对应测试。
