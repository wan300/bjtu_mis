Why this app

聚合校园服务

应用直接访问 BJTU CAS、MIS、AA、VE、Coremail 等校园服务，在设备本地保存加密凭据、Cookie 与 Room 数据快照，让常用信息更快抵达手机端。

01

学习信息聚合

课表、成绩、考务、校历、作业、选课、空教室、课程资源与回放按使用场景归并。

02

本地同步快照

已同步数据保留在本地，网络波动或校园服务临时不可用时仍可查看关键内容。

03

作业辅助工作区

作业要求与附件可交给内置 Open WebUI Agent，用于整理资料、生成步骤或输出草稿。

04

校园邮箱衔接

Coremail 文件夹、近期邮件、联系人、草稿与发送确认流程接入移动端和 Agent 工具。

Stations

功能模块

每个模块都是一站独立页面，按教学学习、成绩考务、信息工具、智能助手与账户资料组织。

Developer platform

第三方插件开发

第三方插件是安装在应用内的 Manifest v3 静态 Web 服务。插件通过细粒度权限读取受控校园数据，通过用途拆分的 connect、media、frame 与 navigation origin 使用远程资源；原生桥只对稳定本地 origin 的 main frame 开放。开发者文档覆盖 capability、加密 KV、事务迁移、只读校园代理、制品 digest、lint 和发布检查清单。
